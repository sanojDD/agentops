# AgentOps frontend

React + TypeScript + Vite, plain CSS, no UI library. Full documentation: [../docs/FRONTEND.md](../docs/FRONTEND.md).

```powershell
npm install
Copy-Item .env.example .env.local   # optional: default API address
npm run dev        # http://localhost:5173
npm test           # unit and component tests
npm run build      # type-check and build into dist/
```
