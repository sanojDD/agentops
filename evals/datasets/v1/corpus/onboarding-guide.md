# Getting started

## First steps
Create a workspace, create an API key from the workspace settings, and install the SDK. The JavaScript SDK is installed with npm install @helio/sdk and the Python SDK with pip install helio. Both SDKs read the key from the HELIO_API_KEY environment variable.

## Sandbox
Every workspace has a sandbox environment at api.sandbox.helio.example. Sandbox requests do not count against rate limits and no data is billed. Sandbox keys start with hk_test_ and cannot access production data.

## Templates
The dashboard offers three starter templates: a chat assistant, a document search app and a webhook receiver. Templates create a ready-to-run project in about 2 minutes.

## Help getting started
Helio hosts a live onboarding webinar every Tuesday at 16:00 UTC. Team and Enterprise customers can also book a one-hour onboarding call with a solutions engineer.
