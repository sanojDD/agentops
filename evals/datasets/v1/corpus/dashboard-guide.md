# Dashboard guide

## Overview
The dashboard is the web interface for managing a workspace. It has pages for projects, members, API keys, usage, billing and webhooks.

## Usage page
The usage page shows request counts, error rates and latency for each project. Charts cover the last 30 days and can be filtered by API key.

## Billing page
The billing page lists invoices, the current plan, the payment method and the next billing date. Owners can download invoices as PDF files.
