# Release notes

## Version 2.7
Frankfurt was added as a second data region next to US East. The dashboard now shows monthly usage charts for the last 30 days.

## Version 2.6
The sandbox environment now supports the batch endpoint. Webhook deliveries show their response time in the dashboard.

## Version 2.5
Added the key.revoked webhook event. The audit log can be exported as a CSV file.

## Version 2.4
The rate limit of the Pro plan was raised from 300 to 600 requests per minute. Documentation search was improved.

## Older versions
Release notes before version 2.4 are available on request.
