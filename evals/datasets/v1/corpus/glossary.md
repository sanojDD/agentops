# Glossary

API key: a secret token that identifies a workspace when it calls the Helio API.
Burst: a short period in which a key may send more requests than its normal limit.
Data region: the geographic location where a workspace stores its data.
Project: a container for the resources and settings of one application.
SLA: a service level agreement, the uptime commitment that Helio makes for a plan.
Workspace: the account of a team, which owns projects, members, keys and the subscription.
Webhook: an HTTP request that Helio sends to your server when an event happens.
Sandbox: a separate test environment that does not touch production data.
Postmortem: a written report after a serious incident.
Retry-After: an HTTP header that says how long a client should wait before trying again.
